Beginner guide — setup Bitfocus Companion
  1. Under Output & network enable LAN access, save and restart Field Scoreboard. Allow port 8790 on your trusted Private network only.
  2. In Companion add Generic HTTP Requests. Keep Base URL blank.
  3. Select the correct network adapter, use its IP in the Builder and click Load local API token on the Scoreboard computer.
  4. Pick a command. Copy Method, URL, JSON Body (if present) and Headers into the corresponding Companion button fields.
  5. Test the action. If you get ECONNREFUSED, check restart, LAN IP and firewall. If HTTP 401, check the token.
